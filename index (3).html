Cara Menghosting Website Ini Secara Gratis:

1

Simpan kode di file ini menjadi file bernama index.html di komputer Anda.

2

Buka situs Netlify Drop atau buat akun di GitHub Pages.

3

Jika menggunakan Netlify Drop, cukup drag & drop folder yang berisi file index.html Anda. Website langsung online dalam 10 detik!

4

Anda akan mendapatkan subdomain gratis seperti nama-web-anda.netlify.app atau username.github.io.
